# Task 4 – Three Question Quiz App

## What to do first
1. Keep your original EdBytes starter ZIP and extracted folder untouched.
2. Compare the `questions` array in this sample `app.js` with the question array supplied in the official Task 4 starter.
3. **Use the exact supplied question array for your submission.** Replace only the sample `questions` array in this project if the official starter questions are different. Keep the object property names/shape expected by the official starter.
4. Open `index.html` in a browser and test the quiz.

## Required behavior included
- Displays one question and its answer buttons at a time.
- Gives Correct / Incorrect feedback.
- Prevents multiple answers from counting the same question twice.
- Displays the final score out of three.

## Files
- `index.html` – page structure
- `style.css` – responsive styling
- `app.js` – question data and quiz behavior
- `TEST-NOTES.md` – test record template
- `PASS-CHECKLIST.md` – required checks

## Run
Double-click `index.html` to open it in a modern browser. No installation is required.
